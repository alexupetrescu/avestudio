How it works
  • Pick the school and class (or type a new class name).
  • Reference faces: one clear portrait per child, file named Nume-Prenume.jpg (e.g. Popescu-Ana.jpg). A child is created for each new name, or linked to the one the teacher already added.
  • Class photos: everything from the shoot. Each photo gets web + thumbnail variants and is matched to children by face (and by the old nume (1).jpg naming, if used).
  • Photos nobody is recognised in land on the Face review page for a quick manual assignment.
